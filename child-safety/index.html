子どもの安全基準（CSAE対策方針）

Chem - BL創作漫画・イラストSNS

Chem Labs（以下「当方」といいます）は、当方が提供するアプリケーションおよびこれに関連するウェブサイトその他の関連サービス「Chem - BL創作漫画・イラストSNS」（以下「本サービス」といいます）において、児童の性的虐待および搾取（CSAE: Child Sexual Abuse and Exploitation）、ならびに児童の性的虐待を描写するコンテンツ（CSAM: Child Sexual Abuse Material）を固く禁止します。本ページは、当方が定める児童の安全に関する基準と取り組み、ならびに通報・連絡先について説明するものです。

本ページに定める基準は、当方の利用規約およびプライバシーポリシーの一部を構成し、これらと一体として適用されます。

第1条（CSAEの定義）

本ページにおいて「CSAE（児童の性的虐待と搾取）」とは、児童を性的に搾取し、虐待し、または危険にさらすコンテンツおよび行為をいい、以下を含みます。

  1. 性的搾取を目的とした児童への性的な誘いかけ（グルーミング）
  2. 児童に対するセクストーション（性的な内容を用いた脅迫・恐喝）
  3. 性的目的での児童の人身売買
  4. 児童の性的虐待を描写するコンテンツ（CSAM）の作成、保有、共有または拡散
  5. その他、児童に対する性的搾取・性的虐待に該当する一切のコンテンツおよび行為

本ページにおいて「児童」とは、18歳未満の者をいいます。なお、実在の児童を対象とするものに限らず、実在しない人物を描いた創作物（イラスト・漫画等）であっても、児童または児童に見える人物を性的に描写し、または児童の性的虐待を想起させるコンテンツは、本サービスの安全基準上、禁止の対象とします。

第2条（禁止事項）

当方は、CSAEに対して一切の例外を認めない方針（ゼロ・トレランス）を採用しています。ユーザーは、本サービスにおいて以下の行為を行ってはなりません。これらは利用規約第7条（禁止事項）に定める禁止行為にも該当します。

  1. 児童ポルノまたは児童虐待に該当する、またはそのおそれのあるコンテンツを発信、投稿、編集または表示する行為
  2. 児童の性的搾取、性的虐待またはこれを想起させるコンテンツを発信、投稿、編集または表示する行為
  3. 性的搾取を目的として児童に接触し、または児童を誘引する行為（グルーミング）
  4. 児童に対するセクストーションその他の脅迫・恐喝を行う行為
  5. 実在の児童について、顔合成その他の手法により、本人の同意の有無にかかわらず性的に加工し、または裸体もしくは性的行為を描写したコンテンツを発信、投稿、編集または表示する行為
  6. その他、前条に定めるCSAEに該当し、または該当するおそれのある一切の行為

第3条（年齢に関する基準）

  1. 本サービスは16歳以上の方に限り利用することができ、16歳未満の方を対象としていません。
  2. 18歳未満の未成年者は、法定代理人の同意を得た上で、本サービスの全年齢向け機能に限り利用できるものとし、R-18コンテンツを投稿し、閲覧し、または検索することはできません。
  3. 当方は、必要に応じ、ユーザーに対し年齢または法定代理人の同意の有無に関する確認資料の提出を求めることができます。年齢または同意に関して虚偽の申告があった場合、当方はアカウント停止、コンテンツ削除その他必要な措置を講じることができます。

第4条（当方の取り組み）

当方は、CSAEを防止し、児童の安全を確保するため、以下の措置を講じています。

  1. 通報機能の提供 — ユーザーが、不適切なコンテンツやアカウントを本サービス内から通報できる機能を提供しています。
  2. コンテンツの審査・削除 — 通報または当方の認知により、本基準もしくは利用規約に違反する、またはそのおそれのあるコンテンツを発見した場合、当方は当該コンテンツを事前の通知なく非公開化または削除することができます。
  3. アカウントの停止・削除 — CSAEに該当する行為を行ったユーザーについて、当方は事前の通知または催告なく、アカウントの停止または削除を行います。
  4. 成人向けコンテンツの管理 — R-18コンテンツについて、表示区分・閲覧制限・タグ設定による管理を行い、未成年者による閲覧を制限しています。
  5. 関係当局への通報・協力 — CSAEまたはCSAMを認知した場合、当方は、法令および事案の内容に応じて、関係当局または専門機関への通報・報告を行い、その調査・捜査等に協力します。

第5条（通報の方法）

CSAEに該当する、またはそのおそれのあるコンテンツや行為を発見された場合は、以下のいずれかの方法で速やかに通報してください。当方は、CSAEに関する通報を重要な安全上の問題として取り扱い、速やかに確認します。

  1. アプリ内からの通報 — 該当する投稿またはアカウントの通報機能をご利用ください。
  2. メールでの通報 — 下記「お問い合わせ・連絡先」のメールアドレスまで、件名に「児童の安全に関する通報」と明記のうえご連絡ください。

緊急を要する場合、または児童が危険にさらされていると思われる場合は、当方への通報に加えて、ためらわずに最寄りの警察（緊急の場合は110番）その他の関係当局へ連絡してください。

第6条（関係当局・専門機関）

CSAE・CSAMに関しては、当方への通報のほか、以下の機関へ通報・相談することができます。

  • 警察（緊急時）: 110
  • 警察相談専用電話: #9110
  • 一般社団法人インターネット・ホットラインセンター（日本）: https://www.internethotline.jp/
  • NCMEC CyberTipline（米国・国際）: https://report.cybertip.org/

第7条（関連法令の遵守）

当方は、児童の安全に関する適用法令を遵守します。これには、日本国における「児童買春、児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律」（児童買春・児童ポルノ禁止法）、「児童福祉法」その他の関連法令、ならびにユーザーが所在する国・地域において適用される児童の保護に関する法令が含まれます。
